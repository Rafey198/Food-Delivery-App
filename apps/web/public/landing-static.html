12 AI agents working behind the scenes

FoodPilot ships with a real agent registry. Each agent is self-describing, role-gated, and exposes run(input) with structured reasoning, confidence, and the tools it used — visible in the admin playground.

Customer

Meal Assistant Agent

Conversational ordering. Parses budget + diet, returns 3 grounded picks from real menus. Never hallucinates dishes.

Customer

Recommendation Agent

Ranks restaurants and dishes with weighted, explainable signals (rating, speed, price-fit, popularity, history).

Customer

Support Agent

Triages messages, classifies intent (refund/delay/wrong order), drafts a polite reply, escalates high-severity tickets.

Customer

Nutrition Coach Agent

Picks meals that fit your daily calorie budget and goal (weight loss, muscle gain, low-sodium).

Customer

Substitution Agent

If an item goes out of stock, finds the best dietary-safe substitute by tag overlap, allergens and price proximity.

Merchant

Review Intelligence Agent

Summarises reviews into highlights, complaints, sentiment, and AI-drafted polite replies.

Merchant

Menu Tagging Agent

Auto-tags new menu items with cuisine, dietary, allergens, spice level. Flags HALAL/VEGAN/allergens for merchant confirmation.

Operations

Dispatch Agent

Multi-objective courier ranker with fairness rotation. Each offer ships with reasoning ("Distance 0.6 km; needs more jobs").

Operations

Demand Forecast Agent

24-hour zone-level forecast with peak boost and confidence. Same interface for a future ML model.

Risk

Fraud Detection Agent

Velocity + card-cycling + IP-country + chargeback signals. Returns BLOCK / REVIEW / APPROVE with visible reasons.

Growth

Churn Prediction Agent

RFM-based churn probability + segment (LOYAL / DORMANT / AT_RISK / CHURNED) + tailored retention play.

Pricing

Pricing Optimisation Agent

Transparent surge: peak hour + weather + courier supply + demand, capped at 1.5x. Every reason shown.
